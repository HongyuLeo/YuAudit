# Data handling

Default processing is local. No telemetry or cloud service is implemented. Optional AI uses loopback HTTP only and disables proxies and redirects. Source files are opened read-only. Reports and last-session files contain business information; store them according to your own data policy.

Treat imported documents as untrusted. Spreadsheet formula injection is neutralized on export. File-size and row limits bound workload; keep parser dependencies updated. This application is not a malware scanner. Source opening uses the OS-associated application and requires an explicit user action.

For security defects, report minimal fictional reproduction data without credentials or business records to the repository maintainers through a private channel once the repository has been published.
